Dokumentasi Bos

Bos (Browser Security) adalah ekstensi Chrome/Edge (Manifest V3) untuk memblokir iklan, redirect otomatis, popup/tab iklan, sekaligus mendeteksi indikasi pencurian data. Versi 1.8.4, Chrome/Edge 119+.

Semua proses berjalan lokal di browser. Ekstensi tidak mengirim data ke server mana pun.

Instalasi

  1. Clone repository (atau unduh ZIP lalu ekstrak).
  2. Buka chrome://extensions atau edge://extensions.
  3. Aktifkan Developer mode.
  4. Klik Load unpacked dan pilih folder repo.
  5. Setelah mengubah kode, klik Reload pada kartu ekstensi lalu refresh halaman web.
git clone https://github.com/didikmulyadi/bos-browser-security.git

Tidak ada proses build. Semua file dimuat langsung.

Penggunaan

  • Toggle kanan atas menyalakan atau mematikan seluruh proteksi.
  • Network ad filter menunjukkan status ruleset iklan jaringan.
  • Whitelist domain ini mengecualikan situs aktif dari proteksi.
  • Pemeriksaan keamanan menampilkan status detektor. Dot hijau berarti aktif; angka merah adalah jumlah peringatan; toggle kecil di kanan mengatur tangani otomatis per item.
  • Peringatan terbaru dikelompokkan per severity. Klik kartu untuk melihat penjelasan, host/detail, waktu, dan status penanganan.
  • Reset stats dan hapus hanya membersihkan data tab aktif.

Whitelist domain

Whitelist mengecualikan satu domain dari pemblokiran dan deteksi tanpa mematikan ekstensi secara global. Cocok untuk situs yang fiturnya terganggu oleh proteksi.

  1. Buka situs yang ingin dikecualikan.
  2. Klik ikon Bos, lalu Whitelist domain ini.
  3. Untuk mengaktifkan kembali, klik Batalkan whitelist.

Domain disimpan dalam bentuk domain dasar (mis. example.com) sehingga subdomain ikut dikecualikan. Whitelist diterapkan lewat aturan allow DNR berprioritas tinggi, dan content script berhenti memblokir/deteksi untuk situs tersebut.

Whitelist mengizinkan request jaringan dari situs itu. Hanya tambahkan domain yang benar-benar dipercaya.

Technology profiler

Bos mendeteksi library, framework, package, CMS, analytics, dan CDN yang dipakai halaman beserta versinya bila tersedia. Hasil ditampilkan per tab di popup.

  • Global window: React.version, jQuery.fn.jquery, Vue.version, angular.version.full, _.VERSION, dan lainnya.
  • DOM: #__next, [data-reactroot], [ng-version], [data-v-app], .shopify-section, link[href*=wp-content], dan lainnya.
  • URL asset: pola @version, nama file seperti jquery-3.6.0.min.js, atau query ?ver=; termasuk resource dari performance.getEntriesByType("resource").
  • Cookie: PHPSESSID, laravel_session, wordpress_, _shopify, __cf_bm, _ga, dan lainnya.
  • Inline script & CSS: token seperti __NEXT_DATA__, __NUXT__, webpackChunk, gtag(, dataLayer, --tw- (Tailwind), --chakra-.
  • Meta tags: WordPress, Drupal, Joomla, Ghost, TYPO3, Hugo, Webflow, Framer, dan lainnya.
  • HTTP header: Server, X-Powered-By, X-AspNet-Version, X-Generator, X-Drupal-Cache, X-Shopify-Stage, X-Vercel-Id, X-Nextjs-Cache, CF-Ray, Via, Set-Cookie.

Implikasi umum diterapkan: WooCommerce/Elementor → WordPress, Next.js/Gatsby/Remix → React, Nuxt → Vue.js, SvelteKit → Svelte+Vite, Laravel/CodeIgniter → PHP, Django → Python. Versi bersifat best-effort, diambil dari global, atribut, URL, atau header. Ikon brand asli berasal dari Simple Icons (CC0 1.0) dan di-bundle lokal; fallback monogram kategori bila logo belum tersedia.

Tangani otomatis

Setiap item memiliki toggle kecil di popup. Saat aktif (default), item dengan severity sedang/tinggi akan diblokir atau dihentikan. Saat dimatikan, item tetap dideteksi dan dicatat, tetapi tidak mengubah perilaku halaman.

Item severity rendah (mis. fingerprint canvas) hanya dipantau karena pemblokiran berisiko merusak situs. Pilihan disimpan sebagai map autoHandle di chrome.storage.local.

Batasan

  • Bukan pengganti penuh uBlock Origin/EasyList. Daftar domain statis dan terbatas.
  • JavaScript tidak bisa membaca cookie domain lain (same-origin policy). Yang dideteksi adalah upaya eksfiltrasi dan penulisan cookie lintas domain.
  • Script inline yang diinjeksi parser awal bisa sudah dieksekusi sebelum dianalisis. Script dinamis diperiksa sebelum dieksekusi.
  • Tangani otomatis bisa merusak fitur situs. Matikan per item bila perlu.
  • Frame sandbox tanpa allow-scripts dilewati agar tidak memicu error.
  • Di halaman challenge Cloudflare (mis. "Just a moment..."), auto-handle keamanan dinonaktifkan sementara agar verifikasi bisa selesai. Jika masih gagal, whitelist domain tersebut sementara.
  • Data per tab bersifat sesi: hilang saat tab ditutup, navigasi ulang, atau ekstensi di-reload.
  • Iklan first-party dari domain situs sendiri tidak selalu terdeteksi.

Challenge Cloudflare (`Just a moment...`)

Jika verifikasi berputar terus dan Network menampilkan 401 pada /cdn-cgi/challenge-platform/.../pat/, itu respons dari Cloudflare, bukan pemblokiran ekstensi. Domain challenge sudah di-allow di rules/allow.json dan di-bypass di hooks.

  • Reload paksa (Ctrl+Shift+R), lalu bersihkan cookie/site data situs.
  • Izinkan cookie pihak ketiga untuk challenges.cloudflare.com sementara.
  • Coba whitelist domain atau nonaktifkan ekstensi sebentar untuk memastikan.
  • Pastikan jam sistem benar dan tidak memakai VPN/proxy mencurigakan.
  • Ekstensi tidak mencoba melewati verifikasi Cloudflare.

Pengembangan

Validasi sintaks:

node --check src/background.js
node --check src/content/isolated.js
node --check src/main/main-world.js
node --check src/main/security.js
node --check src/main/tech.js
node --check src/popup/popup.js
node --check src/shared/patterns.js
node --check src/shared/checks.js

Validasi JSON:

node -e "JSON.parse(require('fs').readFileSync('manifest.json')); JSON.parse(require('fs').readFileSync('rules/ads.json')); console.log('ok')"

Menambah domain iklan: tambahkan ke AD_HOSTS di src/shared/patterns.js dan sinkronkan rules/ads.json.

Menambah pemeriksaan: tambahkan key di src/shared/checks.js, buildChecks() di security.js, serta CHECKS dan SEC_INFO di popup.js. Naikkan versi di manifest.json.
