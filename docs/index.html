Iklan, redirect, dan pencurian data ditangani.

Bos adalah ekstensi Chrome/Edge yang memblokir iklan dan popup, menghentikan redirect otomatis, serta mendeteksi upaya pencurian cookie, token, dan data sensitif. Semua berjalan lokal di browser.

17 pemeriksaan keamanan

Deteksi exfiltrasi cookie, data sensitif, clipboard, kredensial, dan lainnya.

Tangani otomatis per item

Setiap pemeriksaan punya toggle sendiri. Default aktif, bisa dimatikan.

Data per tab

Statistik, alert, dan pemeriksaan tidak tercampur antar tab. Badge per tab.

Whitelist domain

Kecualikan situs tertentu dari blokir dan deteksi tanpa mematikan ekstensi.

Pemeriksaan keamanan

Deteksi berjalan di halaman dan dilaporkan per tab. Severity menentukan apakah permintaan diblokir, dihentikan, atau hanya dipantau.

Severity tinggi

Exfiltrasi cookie/token, cookie lintas domain, akses kredensial, kamera/mikrofon, Payment Request, dan script dari data:/blob:/IP mentah. Diblokir otomatis.

Severity sedang

Data sensitif ke pihak ketiga, IP mentah, document.domain, clipboard, geolocation, iframe tersembunyi, postMessage, dan script obfuscated. Diblokir otomatis.

Severity rendah

Fingerprint canvas dan indikasi ringan hanya dipantau. Tidak memblokir agar situs tidak rusak.

Banner cookie

Banner OneTrust otomatis ditolak dan disembunyikan, mengikuti toggle item Banner cookie otomatis.
